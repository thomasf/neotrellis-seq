Trellis M4 MIDI Drum Sequencer

Standalone 6-voice polyphonic USB-MIDI step sequencer for the Adafruit NeoTrellis M4 (SAMD51 Cortex-M4 at 120 MHz, 8×4 RGB elastomeric keypad). Features polyrhythmic track lengths, 4-level velocity dynamics, generative algorithmic transforms, and 256-step undo/redo.

Specifications & Architecture

FeatureDescription
Voices6 independent drum channels (Voice 0–5), default MIDI notes 36–41 (C1–F1) on Channel 1.
Pattern Memory16 pattern slots per voice (96 total), switchable on the fly without interrupting playback.
Track LengthIndependent length per voice (1–16 steps) for evolving polyrhythms and phase meters.
Velocities4 expressive levels: Accent (127), Normal (99), Ghost / Muted (50), and Rest / Silence (0).
Undo / Redo256 edits deep across all voices. Swaps and all-voice transforms undo/redo in a single press.
TransformsAlgorithmic generators: Euclidean, Game of Life, Rule 30, Shift, Echo, Invert, Drift, Declutter, Fill Empty.
MIDI TransportClass-compliant USB-MIDI following host clock (24 PPQN), start, stop, continue, and SPP.

Voice Protect Behavior

When Voice Protect is enabled for a voice, it is shielded from any feature that modifies all voices at once:

  • Playing Note Flash: When a note plays, the voice pad flashes red (COLOR_RED) if protected, instead of white (COLOR_PPOS).
  • All-Voice Transforms (TRANSFORM + ALL + STEP): Protected voices are skipped and retain their patterns.
  • Kit Presets (TRANSFORM + ALL + ACCENT + STEP n): Protected voices are not overwritten.
  • Dropout (TRANSFORM + ALL + CLEAR): Protected voices are never silenced.
  • Polymeter / Odd Meters (TRANSFORM + ALL + LEN): Protected voices preserve their existing pattern length.
  • Sync Lengths (TRANSFORM + ALL + STEP 13): Protected voices do not have their pattern length changed.
  • Declutter (TRANSFORM + ALL + STEP 11): Protected voices are never chosen for silencing.
  • Game of Life (TRANSFORM + ALL + STEP 12): Protected voices provide living neighbors to adjacent tracks, but their own pattern is protected from modification.
  • All-Voice Pattern Slot Selection (ALL + STEP n): Protected voices stay locked to their current pattern slot.

Direct editing when explicitly selecting the voice and targeted voice swapping (TRANSFORM + VOICE v) remain available.

Playback Path Modifiers

Row 2 provides 4 independent playback path modifiers for each voice. Modifiers alter how the playhead traverses the steps in real time without altering or corrupting the underlying pattern data. All 4 modifiers can be combined freely for unusual, complex rhythmic evolutions:

  • Ping-Pong (STEP 5): Plays forward through the pattern, then bounces back in reverse without repeating the start and end steps (period is 2L - 2 steps for length L > 1). For example, a 4-step pattern cycles 0 → 1 → 2 → 3 → 2 → 1.
  • Spiral (STEP 6): Scans the 4×4 step grid in an outside-in spiral: clockwise around the outer border (steps 0, 1, 2, 3, 7, 11, 15, 14, 13, 12, 8, 4), then through the inner core (5, 6, 10, 9). For shorter patterns, only steps within the pattern length are visited in spiral order.
  • Phase Slip (STEP 7): Shifts the pattern starting offset forward by +1 step every time a full cycle completes (Steve Reich-style minimalist phasing). Preserves the melodic and rhythmic motif while continuously evolving its placement across the metric pulse.
  • Mutate (STEP 8): Automatically switches between all unused path modifiers every 4 bars in random order without back-to-back repeats (cycling through Stutter, Weave, Drunken, Beat Ping-Pong, Broken Thirds, Downbeat Lock, Pair Swap, Turnaround, and Pedal). Keeps long grooves constantly evolving with fresh organic rhythm.
  • Combining Modifiers: Combining modifiers applies them deterministically in sequence (Ping-Pong → Phase → Active/Mutated Modifiers → Spiral). Combining all four yields complex, non-repetitive phrases that remain locked to the bar structure.
