# SYNTAX GUIDE:
# -----------------------------------------------------------------------------
# - Comments start with '#' and blank lines are ignored.
# - Step tokens:
#     _ or . = Rest / silence (velocity 0)
#     g      = Ghost note (velocity 50)
#     N      = Normal note (velocity 99)
#     A      = Accent note (velocity 127)
#     0..127 = Explicit numeric velocity (e.g. for dynamic rolls / crescendo)
#   Tokens can be grouped with spaces for readability (e.g. groups of 4).
#   Each pattern or track must contain exactly 16 steps.
#
# - Single-Voice Presets:
#     [voice.<index>: <Name>] defines a 16-preset bank for Voice <index> (0..5):
#       Voice 0: Kick / Bass Drum
#       Voice 1: Snare / Clap
#       Voice 2: Hi-Hat
#       Voice 3: Percussion 1 (Low/Mid)
#       Voice 4: Percussion 2 (Mid/High)
#       Voice 5: Percussion 3 (High/Texture)
#
#     Within a voice section, each preset (pads 1..16) is defined as:
#       <pad>: <Preset Name> | <Style / Characteristics>
#       [display: <optional custom representation for HTML table>]
#       <16 step tokens>
#
# - Full 6-Voice Coordinated Kits:
#     [kit.<pad>] defines an coordinated kit for Pad <pad> (1..16):
#       name:  <Kit Name>
#       genre: <Genre>
#       desc:  <Ensemble Behavior / Description>
#       kick:  <16 step tokens>
#       snare: <16 step tokens>
#       hihat: <16 step tokens>
#       perc1: <16 step tokens>
#       perc2: <16 step tokens>
#       perc3: <16 step tokens>
# =============================================================================
